Конкретные кейсы

01Дедлайн.

Ежемесячный дайджест в Timeweb Cloud: статья, рассылка, карточки синхронно с релизами. 12 выпусков в год, ни одного срыва — сейчас фирменный формат компании.

 02SEO и спринты.

Переписал под SEO ≈100 продуктовых лендингов сайта, итерациями, с чек-листом по конверсии и структуре.

 03Креатив.

Бренд одежды Red Flag, работа со стороны Студии Артемия Лебедева — позиционирование и тон-оф-войс с нуля, ключевые страницы сайта.

 04Сложные тексты.

Альфа-Банк, Альфа-Капитал, Т‑Бизнес — структурные продукты и инвестиционный каталог: сложная финансовая механика на понятном языке.

 05Отбор авторов.

Альфа-Банк — сам составил тестовое задание, построил воронку почти из 1 000 кандидатов → выбрал топ-10 по тестовым → сделал 4 оффера.

 06Управление командой.

Т‑Банк — 9 авторов на аутсорсе: задачи, нагрузка, финальная редактура по направлению бизнес-продуктов.

 07Международный контент.

Hostman — весь сайт и продуктовые лендинги на английском, тон-оф-войс под аудиторию разработчиков.

 08Рост ТГ-канала.

Телеграм-канал Timeweb Cloud — ресурсный подход (пост вслед за реальной фичей, не контент ради контента), рост с 2 до 10 тысяч.

 09Система без меня.

Дорожная карта для клиентских кейсов Timeweb Cloud — вопросы для интервью, единая структура, тон-оф-войс. Кейсы выходят на потоке без моего личного участия.
10AI-конвейер — продуктовые страницы.

Собрал в Claude Code конвейер: агенты подбирают SEO-интент через Wordstat, готовят черновик лендинга, прогоняют через скилл очистки от AI-артефактов — весь процесс на потоке, но под моим контролем на каждом шаге.

11AI-конвейер — welcome-страницы личного кабинета.

Беру данные о поведении в личном кабинете из Metabase, чтобы понять, на каком шаге отваливаются пользователи, нейросеть готовит черновик под конкретный сценарий использования, финальную логику и правку беру на себя.

12Свой сайт на вайбкодинге.

Собрал и веду личный сайт с помощью AI-инструментов — не только пишу на нём статьи под SEO, но и сам настраивал техническую часть через нейросети, без разработчика. Площадка для портфолио и практики метрик и аналитики.
